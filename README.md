## Local development

The browser game is an ES-module application. `_layouts/default.html` supplies the Three.js import map and loads `main.js`; `game.js` remains as a compatibility entry point. Character loading prefers `assets/models/swat/swat.gltf`, then `assets/characters/soldier.glb`, and falls back to procedural models if neither exists. Rigged characters should include an animated right-hand bone named `Hand_R`, `RightHand`, `hand_r`, or `mixamorigRightHand`. Optional weapon GLBs can be supplied under `assets/weapons/` as `rifle.glb`, `sniper.glb`, `shotgun.glb`, `smg.glb`, and `knife.glb`; built-in models are used when these files are absent.

Player spawn points are authored per map as world-space `spawnPoints` vectors in `main.js`; the host assigns separate positions, and the joining client validates the host position and moves Player 2 to the nearest open spawn node if its assigned position is blocked. This is client-side validation in the PeerJS/WebRTC architecture, not server-authoritative validation. Solo bots use grid pathfinding and Seek, Cover, Attack, and Dodge states, with line-of-sight checks against solid map tiles; wave two introduces Brutes with 300 health, heavy weapons, and reduced movement speed. Connected private rooms disable training bots so they cannot interfere with peer matches. Head, torso, and limb hits apply 3x, 1x, and 0.5x damage respectively.

Combat bullets, particles, and wall decals use bounded reusable `THREE.InstancedMesh` pools; transient effects and timers are cleared when a match is reset or left. Players receive three seconds of spawn protection, and spawn selection rejects invalid map coordinates and prefers positions outside enemy line of sight. Multiplayer pause is a local overlay only: the peer simulation continues, and leaving disconnects the local peer without sending a match-end message to the remaining player. Hit markers and hit-confirmation skulls animate and clear after one second. Procedural first-person weapon models are used automatically when optional weapon assets are missing. Wall bullet marks use actual 3D wall intersections, preventing floating marks; bot hits use impact particles instead of wall decals.

Multiplayer currently supports two players in a private PeerJS/WebRTC room; it does not provide public matchmaking, multi-peer FFA/TDM, or a server-authoritative anti-cheat model. Positions, health, weapons, and shots synchronize directly between peers, and a player elimination ends the match for both sides. Solo matches continue to use bots. Multiplayer hosts can configure match mode and map only after creating an active private room; the selected configuration is sent to the joining peer when the match starts. The elimination replay is only triggered by a connected player elimination, not by bot kills.

Movement includes jumping with Space, held-space bunny hops, sprint stamina with an exhaustion recovery threshold, and weapon-weight movement speeds. First-person weapon/arm motion follows the jump, and deployment and automatic respawn show a 3-2-1-start countdown. Hip-fire recoil includes camera and weapon kick, reduced while aiming and by suppressors. Press F to inspect, G for a frag, and V for a flashbang. Inspection locks firing, reloading, and ability inputs, but movement and jumping remain available; F or the touch Cancel button ends the inspection, and Escape pauses and cancels it. Flashbangs have a short response delay so players can turn away before exposure is applied. Knife M1 attacks advance one strike per click in a stab, slash, stab cycle, and knife inspection spins in hand while raising the index finger. When the character rig loads, its animated torso, arms, and hands form the first-person viewmodel, with the active weapon attached at the right hand; procedural weapon models remain available if optional weapon assets are missing. Reloads animate the weapon and magazine. With the Combat Knife equipped, right-click raises a parry shield that blocks five incoming ranged bullets before entering a 25-second cooldown. Sniper ADS uses its scope overlay, reduced FOV, and adjustable lower sensitivity; equipped scope optics share that behavior. Iron sights align to the camera. Optics are unavailable on shotguns and knives, and suppressors are unavailable on knives. Remote and procedural AI weapons attach at right-hand sockets; optional rigged enemy models require a `Hand_R` or supported equivalent bone.

The map selector and private-room configuration include Tactical Arena, Battlefield, The Pool Rooms, Iron Foundry, Rooftop, Desert Outpost, and Subway Terminal. Each map has its own layout, atmosphere, collision data, and validated spawn points: the Foundry is an enclosed steelworks with molten vats and catwalks, the Subway is an underground station with platforms, rails, signage, and a parked train, and the Desert Outpost retains its outdoor checkpoint setting. Arena includes a small hidden headphone-wearing duck. Solo play also has Training (respawning target dummies), Infinite (unlimited health and ammunition), and Zombies (melee-only waves). Wave play restores health between rounds, awards credits, drops a medkit and weapon on Wave 5, and adds a scaling boss every 10 waves. Three- and five-elimination streaks activate UAV and airstrike support; headshot and backstab eliminations also unlock persistent achievement toasts. A solo Wave 10+ boss has a 5% chance to drop a physical Sukuna's Finger; collecting it replaces weapon combat with M1 slashes, Q Cleave/Dismantle, F Fuga, and X Domain Expansion for 10 waves, then restores the selected weapon. The drop and power-up are disabled in multiplayer. Credits persist locally and can be spent in the Outpost shop on character skins, weapon camos, and attachment unlocks; attachments are configured per compatible weapon at the separate weapon bench and visibly mount on the gun.

Weapons have individual F-key inspection poses. The sniper has a light movement profile and penetrates up to five lined-up targets, with damage falloff; knife hits use layered slash decals rather than bullet holes. Frag grenades create a larger fireball, sparks, debris, dust, and scorch marks. Flashbangs check facing and wall occlusion, allow a brief turn-away window, and disrupt AI aim. Connected two-player eliminations trigger a synchronized first-person Best Play replay using each client's locally buffered final ten seconds.

The optional SQLite leaderboard API runs on loopback and uses only the Python standard library:

```powershell
python leaderboard_server.py
```

Serve the Jekyll site separately. The game calls `http://127.0.0.1:8765/api` by default; set `window.BLACKSITE_API_URL` before loading `main.js` to use a different API origin. The local API binds only to `127.0.0.1`; do not expose this development server directly to the public internet. Match results remain playable if the API is unavailable, and the leaderboard panel displays the connection status.

Run the backend tests with:

```powershell
python -m unittest test_leaderboard_server.py
```
